# New Aeon CMS — what you get

One-page overview for sales and client kickoff.

## Included

- Bilingual Arabic / English CMS (pages, posts, resources, custom types)
- RTL-aware admin and storefront
- Optional COD e-commerce (catalogue, cart, checkout, orders, coupons, shipping zones)
- Customer accounts with phone OTP (when SMS is configured)
- Media library (local or S3/R2)
- Forms, navigation, SEO (sitemap, robots, schema)
- Theme tokens + custom CSS
- HTML theme packs for marketing pages (home, pages, blog, posts)
- PHP/WordPress theme **conversion** into HTML packs (PHP is never executed)
- Paste-HTML modes for legacy markup (safe / designer / trusted)
- Self-hosted source under a commercial licence; export/backup of client data

## Not included (today)

- Online card or wallet payments (enums exist; checkout is COD)
- Live PHP theme runtime
- Multi-tenant hosting (one instance per licence)
- SMS by default — wire Twilio (or allow console SMS only for emergencies)
- Theme packs for shop / cart / checkout / account (those stay on the builtin React storefront)

## Fit

Best for Jordan / MENA shops that need Arabic+English and cash-on-delivery, and agencies rebuilding HTML or WordPress marketing fronts onto a modern CMS.
