---
name: storage-migration
description: Plan and verify a CMS storage migration without executing it against shared or production data.
disable-model-invocation: true
---

Trace the existing storage abstraction, migration script, identifiers, checksums, retries, idempotency, and recovery path. Build a dry-run and verification plan. Do not execute shared-data movement until the user explicitly approves the exact source, destination, backup, and rollback.
