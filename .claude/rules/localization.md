# Localization rules

- Preserve locale routing, English/Arabic message parity, RTL behavior, accessibility, SEO metadata, sitemap/robots, and structured data.
- Add or update both language variants when behavior or user-facing copy changes.
- Use existing localization helpers rather than introducing parallel message lookup.
